# gld-kiln-cpp

A from-scratch Kiln codec for C++. The import is `#include "kiln/kiln.hpp"` in namespace `kiln`. The generator command is `gld-kilngen-cpp`.

The library encodes and decodes Frozen values and a version-2 tensor directory. It does not wrap another Kiln implementation.
